# 📊 AI Restaurant Business Consultant

An interactive data analytics and machine learning dashboard built using Streamlit to help restaurant owners analyze market trends, customer demand, and business opportunities using Zomato dataset.

---

## 📌 Overview

This application provides intelligent insights for restaurant owners by analyzing real-world restaurant data. It helps in identifying profitable locations, popular cuisines, demand levels, and pricing strategies.

The system uses statistical analysis and machine learning models to support business decision-making.

---

## ✨ Features

- 📍 City & Cuisine Based Market Analysis
- ⭐ Average Rating & Popularity Insights
- 💰 Cost & Demand Evaluation
- 📈 Trend Visualization
- 🤖 AI-Based Business Recommendations
- 📊 Interactive Dashboard
- 🔍 Smart Query Advisor System

---

## 🛠️ Technologies Used

- Python 3
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Zomato Dataset
